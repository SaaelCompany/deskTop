# Кнопка при потере интернета

Программа для Windows работает в сеансе пользователя и не требует прав администратора. Пока интернет есть, на экране ничего нет. Когда интернет пропадает, в правом нижнем углу появляется красный круг с белым восклицательным знаком. Нажатие открывает `C:\Users\Public\Desktop`. Когда интернет возвращается, кнопка исчезает.

Файл настроек не нужен. Значка у часов нет. Папка «Рабочий стол» не меняется: программа не пишет в реестр и не перезапускает Проводник.

Кнопка появляется после двух проверок подряд без интернета и исчезает после двух проверок подряд с интернетом. Проверка раз в 5 секунд, первая — примерно через полсекунды после запуска. Короткий обрыв на одну проверку кнопку не включает. Если ответ проверки неясен, кнопка остаётся в текущем состоянии.

Папка `C:\Users\Public\Desktop` создаётся, если её ещё нет. Если открыть её не удалось, появляется окно «Сервисная служба». Остановить программу можно в диспетчере задач: процесс называется DesktopSwitch.

## Как проверяется интернет

Сначала программа спрашивает статус сети Windows. Если Windows видит интернет, дополнительный запрос не выполняется. Если Windows не видит интернет или не отвечает, выполняется один запрос `http://www.msftconnecttest.com/connecttest.txt` через системный прокси. Ожидаемое начало ответа: `Microsoft Connect Test`. Когда Windows уже сообщила, что интернета нет, этот запрос ждёт не больше 2 секунд.

## Установка

Нужны Windows 10 или Windows 11 с рабочим столом. Программа — это `DesktopSwitch.exe`. Консоли нет. Скрипты выполняются движком Windows PowerShell 5.1 внутри процесса DesktopSwitch и не запускают отдельный `powershell.exe`.

Корпоративная установка — `dist/DesktopSwitch.msi`. Пакет ставится на компьютер (`ALLUSERS=1`). Установка от SYSTEM не запускает монитор в сеансе 0. Автозапуск записан в `HKLM\Software\Microsoft\Windows\CurrentVersion\Run` и срабатывает при входе сотрудника. Ярлык в общую автозагрузку не кладётся. Перед копированием файлов установщик завершает уже запущенный `DesktopSwitch.exe` и удаляет старый `DesktopSwitch.vbs` из общей автозагрузки.

Тихая установка:

```text
msiexec /i DesktopSwitch.msi /qn /l*v C:\Windows\Temp\DesktopSwitch-install.log
```

Код продукта этой сборки: `{C4A81E57-2D60-4F93-B8C1-6E9A3D5F0B28}`. Код обновления, он не меняется между версиями: `{4048E9C4-7965-48DC-A23D-A4554966E57F}`.

Обнаружение для SCCM: установлен этот код продукта, либо существует `C:\Program Files\DesktopSwitch\DesktopSwitch.exe`, либо в `HKLM\Software\SaaelCompany\DesktopSwitch` значение `Version` равно `1.2.41`.

Удаление:

```text
msiexec /x {C4A81E57-2D60-4F93-B8C1-6E9A3D5F0B28} /qn
```

Следующая версия получает новый код продукта и больший номер версии. Код обновления остаётся прежним, и Windows Installer снимает старую копию сам.

Уже вошедшему сотруднику после установки нужен повторный вход либо ручной запуск `C:\Program Files\DesktopSwitch\DesktopSwitch.exe`. Если предыдущая версия переключила рабочий стол на локальную папку, эта версия путь не возвращает: сетевой стол нужно вернуть политикой или вручную.

Журнал пишется в `%LOCALAPPDATA%\DesktopSwitch\desktop-switch.log`. При удалении он остаётся.

Состояние смотрит `Show-DesktopSwitchStatus.cmd` или `DesktopSwitch.exe -Status`.

Скрипт `Install-DesktopSwitch.ps1` включает автозапуск только текущего пользователя и не требует файла настроек. Для всех пользователей компьютера используйте MSI.

## Пробный запуск

Архив `dist/DesktopSwitch-portable.zip` распаковывается на локальный диск. Запускается `DesktopSwitch.exe`. Установка и права администратора не нужны.

Если браузер удаляет отдельный exe сразу после скачивания, берите архив. Файл не упакован и не замаскирован. Если антивирус удаляет и файл из архива, нужна подпись кода компании или исключение. Раздача через SCCM с внутренней шары этот путь обходит.

## Проверка логики

Правила кнопки и статуса интернета лежат в `DesktopSwitch.Logic.ps1` и проверяются без Windows:

```text
pwsh -NoProfile -File tests/Decision.Tests.ps1
```
